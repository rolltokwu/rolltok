## English

I am building **RollTok**, a developer-focused API platform for accessing authentic Chinese AI models through a unified interface.

My focus is practical:

- making model access easier for developers and small teams;
- documenting integrations with AI clients, agents and workflows;
- testing configurations before publishing tutorials;
- explaining model identity, usage and billing clearly;
- improving the path from the first API call to a reliable production workflow.

### What RollTok is about

RollTok is designed to provide access to available Chinese AI models such as **Qwen, DeepSeek, Kimi and GLM**, with OpenAI-compatible and Anthropic-compatible integration paths where supported by the product.

We follow a simple rule:

> The model described to the user should be the model actually called. No undisclosed downgrade or silent model substitution.
